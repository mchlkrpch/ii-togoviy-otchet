ПАКЕТ ДЛЯ ПРОВЕРКИ ОТЧЕТНОСТИ

Состав пакета
Папка «отчет» содержит один итоговый отчет в PDF.
Папка «первичные» содержит 23 исходных файла PDF, DOCX, XLSX и PNG, а также описание области проверки.
Пакет сформирован из файлов папки «вводные». Повторные документы и документы, требующие проверки периода или договора, сохранены для тестирования системы.

Загрузка в приложение
1. Запустите приложение командой python3 src/run.py из корня проекта.
2. Нажмите «Загрузить документы».
3. В качестве итогового отчета выберите PDF из папки «отчет».
4. В качестве первичных документов выберите все файлы из папки «первичные», включая 00_README_область_проверки.txt.
5. Нажмите «Начать проверку».

Параметры проверки
Договор 24/03/15-01.
Период 01.01.2026–31.05.2026.
Целевая строка «3 этап, 2026 г.».
